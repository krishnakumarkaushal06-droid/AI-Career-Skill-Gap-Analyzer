# AI Career & Skill Gap Analyzer — One Page Final

A Flask-based resume skill extraction and career-readiness analyzer. The entire analysis and analytics dashboard render on one page.

## Included
- PDF resume upload and skill extraction
- Weighted career readiness score
- Keyword vs semantic-signal comparison
- Matched and missing skills
- Top career recommendations
- Personalized learning roadmap
- Readiness trend chart
- Latest score breakdown chart
- Analysis history table
- Automatic MySQL history when the existing database is reachable, with SQLite fallback

## Run
Double-click `run.bat`.
